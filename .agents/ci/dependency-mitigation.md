# Picomatch 重复扩展 glob 防护

GHSA-fc5q-39xc-vjpf（CVE-2026-112366）涉及重复扩展 glob 生成指数回溯的正则表达式。2026-11-18 核查时，上游最新 4.0.7 仍在受影响范围内，尚无已发布的修复版本。

`npm ci` / `npm install` 的 postinstall 在生成正则前明确拒绝重复扩展 glob `+(...)`、`*(...)` 及原始正则分组、重复量词；错误为 `HELPER_UNSUPPORTED_GLOB_REPEAT`。不支持这些语法是本项目构建工具的临时兼容性限制。普通星号、globstar、花括号、字符类以及 `@(...)`、`?(...)`、`!(...)` 继续支持。项目现有过滤、文件扫描和构建规则不使用被拒绝的语法。此修复针对 glob 解析边界，不接管调用者直接传入的 RegExp 或手工正则输出。

防护覆盖独立 Picomatch 和 Rollup 的 CJS、ESM、watcher 内嵌副本，共 5 个文件、7 个解析器。脚本校验上游完整源文件 SHA256、安装版本及锁文件副本布局；依赖更新、新副本、补丁缺失、部分应用或源码变更都会失败，需要重新审核。包名、版本及注册表完整性元数据保持原样。

`npm run audit:dependencies` 运行并打印完整的 `npm audit --json --audit-level=high` 结果。原始 npm audit 仍会报告此公告。本地审计只在全部防护文件通过校验时接受这一条已缓解公告及其依赖传播。其他 high/critical 公告、公告升级、报告结构或退出码不一致、网络错误都会阻止发布。回归测试覆盖 7 个解析器的语法限制、常用 glob 的兼容性，以及防护缺失或被改动时的失败路径。

后续应优先换用通过同一回归测试的上游修复版本，并一并移除此防护与公告例外。不要改包版本来隐藏公告，不要放宽审计级别。
