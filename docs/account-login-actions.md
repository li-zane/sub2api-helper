# 账号登录相关操作

| 操作 | 执行内容 |
| --- | --- |
| 检测 Web 会话 | 测活并核对套餐；确认会话缺失、失效或空间不可用时补登 Web。封禁账号保留手动 Web 登录入口，不执行 OAuth。 |
| Codex 授权 | 唯一的普通授权入口。存在刷新令牌时先刷新 Codex OAuth；凭据缺失或令牌明确失效时，检测并复用 Web 会话，失效则先登录 Web，再通过 OAuth 链接授权。 |
| 取消任务 | 停止当前任务，保留已有凭据与日志。再次点击 Codex 授权时按同一策略选路。 |

刷新接口的网络错误、限流、5xx 或异常响应不会触发密码登录，原有凭据继续保留。旧版继续、重试、强制重新开始的独立按钮已合并；兼容 API 保留供旧客户端使用。

## 一键轮换并上传

新导入账号先登录 Web，识别 PlanType 后匹配任务规则。如规则选择一键轮换，顺序为：

1. 复用 Web 会话轮换 2FA，并保存新密钥。
2. 登出所有设备与会话，移除已失效的旧 Web 会话。
3. 使用新 2FA 重新登录 Web，随后完成 Codex OAuth 授权。
4. 同步新凭据到 Sub2API，等待同步完成，不重复上传。

轮换本身包含授权与上传，不再执行前置 Codex 授权；旧版持久队列也跳过重复步骤，保持恢复游标不变。轮换或登出失败时停止后续步骤。协议日志记录 2FA、登出设备、重新登录与授权的分段及实际选路，凭据值仍只保存在私有凭据历史。

查看凭据、设备、空间、日志和下载已有导出文件保留读取入口。正在等待手机、邮箱、2FA 输入或执行自动任务时，冲突操作保持禁用。下载文件是最近一次保存的导出，不代表本次任务成功。

验证：`node test/console-unified-authorization-smoke.mjs`、`node test/console-upload-pipeline-smoke.mjs`、`npm run test:ui:browser`。均使用本地模拟账号。
