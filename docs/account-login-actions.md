# 账号登录相关操作

操作列区分以下流程：

| 操作 | 执行内容 |
| --- | --- |
| 检测 Web 会话 | 测活并核对套餐；确认会话缺失、失效或空间不可用时补登 Web。 |
| 重新授权 | 优先使用 Codex 刷新令牌更新授权；令牌失效时转入登录授权。 |
| 继续授权 | 恢复已有 Codex 授权检查点，继续邮箱、2FA、手机绑定等步骤。 |
| 重试授权 | 没有可恢复的检查点时重新尝试授权。 |
| 重新开始授权 | 跳过刷新令牌，清除旧 Codex 授权检查点并重新申请授权。仍可复用有效 Web 会话；Web 失效后才补登。 |

服务重启后根据实际检查点文件恢复“继续授权”能力，不根据上次失败或取消的文案猜测。已有旧授权导出文件不妨碍继续未完成的授权。取消当前任务后可以选择继续，也可以重新开始。

查看凭据、设备、空间、日志和下载已有导出文件保留读取入口。批量任务或账号正在等待手机、邮箱、2FA 输入时，修改凭据、切换空间和登出等冲突操作继续禁用，并显示具体原因。下载的是最近一次已保存的导出文件，不代表本次授权已成功。

验证：`node test/console-authorization-actions-smoke.mjs`、`npm run test:ui:browser`。测试使用本地模拟账号，不操作线上账号。
