# 降智静置冷却

在“降智检测设置 → 降智冷却”启用总开关，分别选择“长效账号降智后冷却”“轮转账号降智后冷却”，设置 1–43200 分钟的冷却时长（默认 60 分钟）。三个开关默认关闭，账号类型按“时效”标签识别；未设置类型的账号不触发。

一次完整检测的最终结论为降智时才进入冷却。前置正则疑似降智但兜底通过、检测失败、证据不足均不触发。手动检测、定时检测和导入后检测共用这一规则。开启设置不会追溯执行旧检测结果。

冷却通过暂停号池调度实现，保持登录凭据和 IP 绑定。期间暂停自动降智、过载、WebSession 探测、自动修复及 IP 轮换；仍可主动发起诊断检测，诊断不会提前解除或延长现有冷却。已受理的请求不作撤销。

到期直接恢复本次冷却暂停的账号，不先复检或重新登录。原本停用的账号不会被启用；手动停用／启用优先并接管相关账号。过载冷却、会话维护、账号永久停用和后端切换不会被本次冷却覆盖。关闭总开关或类型开关只停止新增冷却，已开始的冷却按原期限结束；修改时长对后续冷却生效。

状态保存在私有 `degradation-cooldown.json`，先保存恢复意图再修改调度。重启保留截止时间；部分暂停或恢复失败时保留待处理记录并重试，列表不完整时不恢复。账号的降智检测栏显示冷却截止时间和重试状态。
