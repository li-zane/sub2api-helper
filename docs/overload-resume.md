# 过载冷却的类型开关与恢复

任务设置的“过载 → 自动冷却”提供“长效账号过载后冷却”“轮转账号过载后冷却”两个独立开关。默认开启以保留旧行为，账号仍需开启自己的冷却开关。类型按“时效”标签识别；没有类型标签时沿用账号原有开关。关闭某类只停止该类的新冷却，不提前恢复已在冷却的账号。

过载冷却账号手动启用成功后，清除本轮冷却操作记录、截止时间、触发原因和冷却侧缓存计数，保留自动冷却开关及统计曲线。恢复当格不复用旧次数再次冷却，下一格继续判断。手动启用失败保留原冷却恢复责任，等待重试。

手动恢复和冷却到期恢复，均先持久保存“按降智处理”的状态。该状态用于降智筛选、条件分组、并发和优先级策略；页面明确标为等待检测，原来的真实检测记录不被改写，也不新增虚构检测轮次。状态在重启后保留并按后端隔离。

手动恢复会追加一次降智检测，即使该账号的自动检测开关关闭，也按已配置的模型、前置正则和糖果／指纹轮换顺序检测。没有模型配置或账号暂不满足检测条件时保留待检，待具备条件再执行。一次检测失败或证据不足时继续按降智处理；有效检测通过或降智结论会替换暂定状态。冷却到期自动恢复仍遵循原有自动检测设置和间隔。

恢复状态本身不会触发降智冷却；只有真实检测最终判为降智且符合降智冷却设置，才按该设置进入新的静置冷却。冷却前登出、结束后重新授权的现有开关继续生效。
