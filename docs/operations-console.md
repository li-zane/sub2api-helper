# Helper 运营功能

- **代理配置 → 分配与成本**：按号池节点停止或恢复新分配，不会停用节点、解绑或迁移现有账号。购入成本按同一号池的出口 IP 合并；添加日期来自号池创建时间，不把首次扫描当作今天购买。
- **账号列表 → 暂停巡检**：状态列标记「已暂停」，恢复后回到原任务状态。按账号暂停 helper 发起的 Web 会话、模型检测、过载统计和异常自动重登。不会关闭号池流量，也不会撤销已经受理的操作。恢复后沿用原有检测规则。手动操作仍受各自原来的权限与健康状态限制。
- **历史订阅**：跟随控制台亮色；“未检测”表示没有有效结论。“加入 … 后观测到降智”以加入时间和第一次观测到状态变化的时间计算，而非推测实际发生时间。迁移已有的有效轮次，不从错误、超时或缺失样本推断正常。
- **每日收支**：北京时间自然日，人民币。复用账号列表的购入成本、号池实际消费字段及售价倍率；列表累计消费不直接当作日收入。当天所有号池 OAuth 账号（不含 API Key）的日消费折算为收入；仅当天新购的账号、IP 计成本，利润为两者之差。后台每五分钟采样；跨日后用原日倍率结账。七日趋势按所选日期及前六天展示。历史页只读 SQLite 快照，不因打开页面向号池回查。缺失记录和采样不完整会明确提示。没有历史日账时不补造账目。
- **账号列表 → 账号对话测试**：直接读取所选 OAuth 账号的上游文本模型目录，支持刷新，不依赖号池已添加的模型，沿用现有单账号检测通道发送问题。该通道不通过号池计费网关，可能消耗上游额度。账号禁用、限流或身份不匹配时不发送。一次点击只提交一轮；同账号不能重叠生成；可以关闭窗口做其他工作，再打开查看回答。最近 80 轮保存在 helper，必要的最近上下文只在同一号池和账号内复用。服务意外中断不自动重发。删除账号时同时删除其对话。
- 状态与日账位于 helper 数据目录内的 `helper-operations.sqlite`。备份使用现有停服备份流程，或使用 SQLite 的一致性备份；不要在服务运行时只复制数据库主文件而忽略 WAL。
