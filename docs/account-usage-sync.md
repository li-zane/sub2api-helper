# 账号用量同步

代理 IP 卡片按出口统计自开始记录以来绑定过的去重账号数。账号状态和用量同步时，Helper 读取号池账号的 `last_used_at`，取能归属到该出口的最新请求时间。换绑后从新绑定的观察时间开始归属请求。首次观察时，若账号和代理配置的最后修改时间都早于请求，可补记这一次请求。历史统计保存在本地账本中，按后端隔离。

点击账号的 IP 打开“切换绑定 IP”，可查看该账号历史使用的 IP，按出口 IP 去重并标注当前绑定。列表显示该账号在对应出口的上次请求时间，最近使用的排在前面；尚无请求时间的绑定显示“暂无请求时间记录”。手动切换、只换绑及自动轮换均沿用同一份持久化历史，代理节点删除和服务重启后记录仍保留；修改登录邮箱后合并关联邮箱的记录。历史仅覆盖 Helper 已记录的绑定，直连时不推测公网出口，未留存的更早记录不作补造。代理列表读取失败时，已有历史仍可查看。

Helper 的用量分为两类，均由 Sub2API 提供：

- **窗口额度**：5 小时、7 天或 30 天百分比、剩余额度、重置卡。账号列表读取 Sub2API 保存的快照；页面约每 0.9 秒刷新列表，服务端账号快照默认缓存 15 秒。页面同步与服务端定时同步默认每 15 秒执行，间隔可在任务设置修改。这个过程不会每次主动请求 OpenAI，上游快照的更新时机由 Sub2API 决定。
- **累计 A/U/T**：`A` 为账号实际计费（`total_account_cost`，含账号倍率），`U` 为用户实际收费（`total_actual_cost`），`T` 为总 Token（`total_tokens`，包括输入、输出和缓存）。通过 `/api/v1/admin/usage/stats` 按远端账号 ID 查询，范围从 `1970-01-01` 到当前 UTC 日期，覆盖 Sub2API 留存的全部历史；不使用默认为最近 30 天的账号详情接口。同邮箱多个远端 OAuth 账号 ID 去重后相加。

累计统计由服务端后台读取，默认最多 100 个请求并发、每 60 秒同步；并发和间隔都可在任务设置修改，关闭页面后仍运行。普通读取复用成功或失败的缓存，定时同步按配置刷新。统计不会阻塞账号列表。同步失败时保留上次数据并使用虚线标签，悬浮可见说明和时间；缺少字段显示 `—`，不会伪装成 0 或把部分账号的合计当成完整总量。切换 Sub2API 地址或凭据后隔离缓存。

点击用量旁的刷新按钮，会让 Sub2API 主动读取该账号窗口额度和重置卡，同时刷新累计统计（`nocache=true`）。累计统计以 Sub2API 仍保留的日志为准，已清理日志不计入。

Web 会话巡检在扫描账号前也会同步号池状态（复用上述 15 秒缓存），先识别号池封禁，再决定是否恢复会话，避免服务启动时抢先为封禁账号重登。

A/U 金额以 USD 显示；所有累计数字最多保留 3 位有效数字。Token 使用十进制 K/M/B 自动换算，例如 `T 1.23K`、`T 1M`。悬浮标签可查看未缩写的原始值。

监控调度参数详见 [自动化与任务设置](automation.md#任务设置与默认值)。封禁账号跳过累计用量与逐账号配置同步，已有历史显示不代表仍在探测该账号。

账号 IP 定时轮换的设置、排序与恢复规则见 [账号 IP 定时轮换](proxy-rotation.md)。
