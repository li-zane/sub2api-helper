# 账号用量同步

Helper 的用量分为两类，均由 Sub2API 提供：

- **窗口额度**：5 小时、7 天或 30 天百分比、剩余额度、重置卡。账号列表读取 Sub2API 保存的快照；页面约每 0.9 秒刷新列表，服务端账号快照默认缓存 15 秒。页面另外每 15 秒同步号池状态。这个过程不会每次主动请求 OpenAI，上游快照的更新时机由 Sub2API 决定。
- **累计 A/U/T**：`A` 为账号实际计费（`total_account_cost`，含账号倍率），`U` 为用户实际收费（`total_actual_cost`），`T` 为总 Token（`total_tokens`，包括输入、输出和缓存）。通过 `/api/v1/admin/usage/stats` 按远端账号 ID 查询，范围从 `1970-01-01` 到当前 UTC 日期，覆盖 Sub2API 留存的全部历史；不使用默认为最近 30 天的账号详情接口。同邮箱多个远端 OAuth 账号 ID 去重后相加。

累计统计后台读取，最多 4 个请求并发，成功或失败均缓存 60 秒。页面持续访问时，在缓存到期后的下一次号池同步更新，通常约每 60–75 秒。统计不会阻塞账号列表。同步失败时保留上次数据并使用虚线标签，悬浮可见说明和时间；缺少字段显示 `—`，不会伪装成 0 或把部分账号的合计当成完整总量。切换 Sub2API 地址或凭据后隔离缓存。

点击用量旁的刷新按钮，会让 Sub2API 主动读取该账号窗口额度和重置卡，同时刷新累计统计（`nocache=true`）。累计统计以 Sub2API 仍保留的日志为准，已清理日志不计入。

Web 会话巡检在扫描账号前也会同步号池状态（复用上述 15 秒缓存），先识别号池封禁，再决定是否恢复会话，避免服务启动时抢先为封禁账号重登。

A/U 金额以 USD 显示；所有累计数字最多保留 3 位有效数字。Token 使用十进制 K/M/B 自动换算，例如 `T 1.23K`、`T 1M`。悬浮标签可查看未缩写的原始值。
