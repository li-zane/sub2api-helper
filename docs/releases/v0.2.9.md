# Sub2api Helper v0.2.9

- 代理 IP 卡片新增 IPRoyal 订单剩余有效期、历史绑定账号数量和上次请求时间。同一出口的多个协议节点共用历史统计，用量同步时更新请求时间。
- 任务设置新增账号 IP 定时轮换，可配置间隔、是否重新登录，并分别选择降智和未降智账号。优先选择空闲出口，再比较历史绑定数量和上次使用时间；只换绑时同步更新 helper 与号池后续请求出口。
- 降智检测新增前置正则检测，可指定模型、独立提示词、正则表达式，以及命中或未命中时判为疑似降智。前置通过可跳过兜底，疑似降智时由本轮糖果／指纹测试确认，历史记录保留两阶段结果和原文。
- 前置通过并跳过兜底也推进一轮糖果／指纹进度，重启后保留。新功能默认关闭，可在对应设置页开启。
