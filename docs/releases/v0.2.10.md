# Sub2api Helper v0.2.10

- 账号的“切换绑定 IP”弹窗显示历史使用的出口 IP、当前绑定和该账号在对应出口的上次请求时间；按 IP 去重，保留已删除节点的历史。
- 账号备注标签固定高度，悬浮或点击可展开完整内容，并可从预览进入编辑；支持键盘和手机操作。
- 降智检测新增静置冷却设置，总开关与长效、轮转账号开关独立配置，冷却时长可调。最终检测为降智时暂停号池调度，到期直接恢复，保留登录状态和 IP；手动停启用优先，重启保留冷却期限。新开关默认关闭。
- 历史订阅红点覆盖套餐变化、封禁和解除封禁；新增本次未读及最近 24 小时、7 天、30 天筛选，按变化时间倒序，可叠加邮箱和备注搜索。筛选隐藏的账号保留未读，本次查看的变化保留高亮至关闭弹窗。
