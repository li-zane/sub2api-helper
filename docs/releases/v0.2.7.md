# Sub2api Helper v0.2.7

修复重新授权成功后号池仍使用旧令牌，以及会话重建卡在同步阶段时无法取消的问题。

- 重置卡查询收到上游账号 401 时，在原有监控开关、账号资格和重试间隔约束下进入授权恢复；管理员 API 认证失败不会触发账号登录。
- 新 OAuth 凭据写入后，即使号池记录仍是 active，也通过后端清理旧令牌缓存。
- 会话重建完成后恢复原调度开关，额度和限流继续由号池调度器判断，自动重置不会因会话重建暂停而互相等待。人工关闭的账号保持关闭。
- 授权已完成但同步仍在进行时保留取消按钮；取消会中止相关在途请求、清理重试意图，重启后不再继续同步。
- 取消同步后保留已生成的凭据。再次执行 Codex 授权可继续原会话重建的同步，无需重复登录或登出。
