首个带项目版本号的正式版。

- **每日收支**：顶栏增加趋势图标；按所选北京时间日期查看近七日收入、成本和利润。缺失记录留空，负利润正常显示。
- **巡检状态**：关闭账号巡检后，状态列标注「已暂停」并支持筛选；恢复后显示原任务状态。
- **账号对话测试**：可拉取、刷新所选 OAuth 账号的上游文本模型目录。不要求模型事先添加到号池。
- **版本与更新**：点击顶栏版本号可检查 GitHub 正式 Release；确认后安装、等待在途工作结束并核验服务。

运行包：Linux x64 / Node 22。升级步骤见 [版本与更新](https://github.com/li-zane/sub2api-helper/blob/v0.1.0/docs/project-updates.md)。
