# Sub2api Helper v0.2.2

修复 Codex CLI OAuth 已完成 Web 授权、CLI 已写入 `auth.json`，Helper 却一直等待登录结果并最终超时的问题。

- CLI 的本地回调返回 302/303 后，Helper 继续访问容器内同一回环端口的 `/success`，让官方 CLI 正常发出登录完成通知，再校验并导出 Sub2API 凭据。
- 跳转仅允许本地 1455 端口的 `/success`，最多一次；HTTP 200 错误页仍由 CLI 的完成通知判定授权失败。
- 授权日志增加环境 ID、阶段、耗时及回调 HTTP 状态，覆盖导出与清理失败；不记录 token、回调查询参数或上游响应正文。
- 一次性环境、并行 worker 隔离、账号互斥及 UA 手动同步方式保持现有行为。

验证包含回调与日志回归、官方 CLI 0.165.0 在无外网容器内的模拟授权成功/失败全流程、多 worker 清理测试，以及 Linux/Windows 全量检查。继续使用现有 CLI 镜像，无需重建或重新安装 CLI。
