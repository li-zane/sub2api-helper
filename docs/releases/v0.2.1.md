# Codex UA 对比与手动同步

任务设置新增当前 CLI UA、号池 UA 和一致性状态，并提供「重新读取」「同步 CLI UA 到号池」按钮。CLI UA 来自已部署官方 CLI 的实际初始化结果，探测不发起账号授权，结束即销毁临时容器；结果缓存 10 分钟，并发读取共用一次探测。

Codex CLI OAuth 不再读取或写入网关 UA，网关设置接口故障也不阻止凭据导出。仅点击同步按钮时更新全局 `openai_codex_user_agent`，保存后读回核验；两端一致时跳过写入。号池配置或已展示的 UA 发生变化时，要求重新读取后确认。

保留其他网关设置、账号绑定、授权方式和一次性容器清理逻辑。同步按钮立即生效，不依赖「保存设置」，也不切换授权方式。升级本身不执行同步或真实账号授权。

验证覆盖零自动 UA 请求、缓存及强制刷新、手动同步与并发去重、过期对比拒绝、HTTP 访问校验、设置保留、失败与清理，以及桌面/手机端对比、同步、错误恢复和键盘操作。
