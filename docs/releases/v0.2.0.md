# Codex CLI OAuth

任务设置新增「Codex CLI OAuth（账号独立环境）」。官方 CLI 生成授权链接，沿用当前账号的 Web 会话完成授权，CLI 写入 `auth.json` 后转换成 Sub2API 凭据。校验邮箱和工作区后原子保存；每次授权使用全新 tmpfs 容器，保存后销毁，不保留 CLI 登录卷。

同主机多个 worker 可以并行授权不同账号。SQLite 协调锁让同账号串行执行，并序列化全局 UA 更新；回调端口位于各自容器内，不发布到宿主。网关 OpenAI Codex UA 使用 CLI 实际报告的值，保存后读回核对；后续凭据刷新走 Sub2API，不依赖已经销毁的 CLI 环境。

CLI 构建文件和固定版本锁文件随运行包交付；启用前需要准备 Docker 及官方 CLI 0.165.0 镜像。推荐服务用户使用独立的 rootless Docker。现有授权模式与账号设置保持不变，升级不会自动重新授权或修改网关 UA；选择该模式并成功授权时才同步 UA。

验证包含账号/工作区及 callback/state 校验、失败保留、导出先于清理、三个独立 worker 同时运行官方 CLI、异常退出回收和并发重试锁竞争、后续无 Docker 刷新，以及桌面/手机设置交互。Linux CI 增加真实 Docker worker 检查。容器提供状态与进程隔离，不声称提供独立硬件指纹或公网出口。
